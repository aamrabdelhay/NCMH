# NCMH — المجلس القومي للصحة النفسية

بوابة معلوماتية عربية متجاوبة للتعريف بالمجلس القومي للصحة النفسية في مصر، واختصاصاته، وحقوق المرضى، والأخبار والمواد المرجعية المنشورة.

## التقنية
- HTML5 / CSS3 / JavaScript بدون اعتماد على حزم خارجية.
- تصميم RTL ومتجاوب مع الهواتف.
- أزرار Liquid Glass باستخدام `backdrop-filter` مع بدائل تدهور تدريجي.
- النشر على Vercel كصفحة ثابتة من `index.html`.

## مصادر الروابط المعروضة
- وزارة الصحة والسكان: https://www.mohp.gov.eg/
- رئاسة مجلس الوزراء: https://www.cabinet.gov.eg/News/Details/76490
- الهيئة العامة للاستعلامات: https://sis.gov.eg/
- بوابة الأهرام: https://gate.ahram.org.eg/News/5596693.aspx و https://gate.ahram.org.eg/News/5982676.aspx

## ملاحظة اعتماد
هذه نسخة تطويرية أولية وليست قناة حكومية معتمدة قبل مراجعتها واعتمادها من المجلس والوزارة. بيانات الاتصال المعروضة مأخوذة من تقارير سابقة منشورة على موقع الوزارة ويجب التحقق من استمرارها قبل اعتمادها.
