# المجلس القومي للصحة النفسية

موقع عربي من صفحة رئيسية واحدة، بهيكل بوابة حكومية تقليدية وأخبار مصورة في بداية الصفحة، وروابط داخلية للأقسام، ومكتبة تشريعات وروابط مباشرة للنصوص.

## ملفات الموقع
- index.html — الصفحة الرئيسية وكافة الأقسام.
- style.css — الهوية البصرية والتنسيق.
- app.js — قائمة الهاتف وشريط الأخبار المصور.
- assets/council-logo.svg — نسخة متجهية محلية من شعار المجلس المستمد من الصورة المرسلة.
- assets/ministry-logo.svg — شعار وزارة الصحة في صيغة متجهية محلية.
- بقية صفحات HTML القديمة تحول الزائر إلى القسم المقابل في الصفحة الرئيسية.
