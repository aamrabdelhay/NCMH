# NCMH — المجلس القومي للصحة النفسية

بوابة عربية RTL متجاوبة للتعريف بالمجلس واختصاصاته وحقوق المرضى، مع صفحات مستقلة للأخبار والمراجع القانونية والتواصل.

## الصفحات
- index.html — الرئيسية.
- about.html — النشأة والتشكيل والاختصاصات والتمييز عن الأمانة العامة.
- rights.html — حقوق المريض النفسي (المواد 36–40 من القانون).
- news.html — أخبار وبيانات مؤرخة مع بحث وتصنيف.
- library.html — قانون 71/2009 وتعديل 210/2020 واللائحة 128/2010 ومواد مرجعية.
- contact.html — قنوات التواصل والشكاوى، مع توضيح تاريخ مصدر الرقم المنشور.

## الهوية والتقنيات
HTML/CSS/JS ثابتة، تصميم RTL، أزرار Liquid Glass، شعار المجلس الذي زود به صاحب المشروع، شعار وزارة الصحة في رأس الصفحات، تصميم متوافق مع الهواتف، بحث للأخبار والوثائق، sitemap وrobots وweb manifest.
